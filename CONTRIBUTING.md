# Retrieval Chatbot

A simple Retrieval-Augmented Generation (RAG) chatbot built using Python.

## Technologies Used

* Python
* Sentence Transformers
* FAISS
* Google Colab

## Features

* Stores knowledge documents
* Retrieves relevant information
* Answers user questions based on stored data

## Example

Question: What is ECE?

Answer: ECE stands for Electronics and Communication Engineering.
